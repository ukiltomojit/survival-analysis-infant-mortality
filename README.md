## Survival Analysis of Infant Mortality in India

Multilevel survival analysis using NFHS-5 data to identify child, maternal, 
and socio-economic determinants of infant mortality.

### Methods
- Cox Proportional Hazards Model
- Weibull, Exponential, Log-logistic parametric survival models
- District and PSU-level multilevel factors
- AIC/BIC model comparison

### Tools
- Stata
